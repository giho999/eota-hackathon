# 이어타 (EOTA)

항공·철도 환승 시나리오에서 **열차 탑승 성공 확률**을 몬테카를로로 계산해 근거와 함께 제시하고,
여유 시간이 있으면 대전역 인근 관광 코스를 추천하는 챗봇. **내일로 해커톤 2026 출품작**.

## 배포 URL

**https://code-seven-blush.vercel.app**

스마트폰으로 바로 접속하려면 QR코드를 스캔하세요:

![이어타 QR](eota-qr.png)

## 기능

| 유형 | 시나리오 | 설명 |
|---|---|---|
| A | 비행기 → 기차 | 입국 후 열차 탑승 확률, 안전 추천(90%+ 중 가장 이른) + 가장 빠른 선택 |
| B | 기차 → 비행기 | 역산 계산, 도심공항터미널 사전 체크인 비교 (차별점) |
| C | 기차만 | 출발역·도착역·희망시각 3클릭으로 완결 |

- 근거 타임라인 + 분포 히스토그램 (임계선 = 성공 영역)
- 여유 30분 이상 시 대전역 인근 관광 코스 추천 (예산 막대)
- 실시간 지연 감지 알림 (10%p 이상 하락 시에만)

## 로컬 실행

```bash
npm install
npm run dev       # http://localhost:3000
npm test          # vitest
npm run build
```

API 키(`DATA_GO_KR_KEY`)가 없으면 전체가 mock으로 동작합니다.
